# RPG GPS Kit — build a game from GPS coordinates

[English overview and screenshots](README.en.md) · [Català](SKILL.ca.md)

The engine behind the Roda de Berà adventure, packaged as a reusable kit. The map comes from OSM;
tiles and sprites are generated by `tools/make_tiles.py` and `tools/make_sprites.py`, using the
32-color palette in `tools/pixel.py`. Music and sound effects are synthesized in `src/audio.lua`,
interiors in `src/world/procgen.lua`, and quests are generated from local data. No external art or audio files are required.
This English skill describes the existing engine; in-game text remains in Catalan.

## The kit and derived games

Repository: [aewnor/rpg-gps-kit](https://github.com/aewnor/rpg-gps-kit). Start from the kit for a new town;
work in the game's own repository when changing an existing game. Check `git status` and the revision
before copying changes: Roda and the kit may have different features. Preserve local changes; deployed
changes may not have been committed yet.

For interiors, graphics, mobile controls or web deployment, read [references/maintenance.md](references/maintenance.md).
Distinguish engine invariants from Roda-specific examples. Updating this guide does not automatically port code into the kit.

## Workflow

The placeholders below must be replaced; square brackets indicate an optional argument.

```sh
cp -r rpg-gps-kit ~/game-<place> && cd ~/game-<place>
python3 tools/new_location.py --name "<Place>" --lat <lat> --lon <lon> [--size-km 3.2]
make newmaps        # make_streets → make_services → make_missions → make maps
make art            # make_locals (OSM signs) → make_tiles → make_sprites
make validate       # validate_content.py + palette_check.py: expect “VALIDACIÓ OK”
make unit           # check the exit code: some tests print OK before failing
love .              # or web server: python3 tools/web_server.py (port 8102)
```

- `--size-km`: 3.2 km (800×800 tiles) suits a town; the Roda map uses 6.4 km. Larger maps take longer
  to build with `make maps` and use more browser memory. Side lengths are always multiples of 32 (the engine's chunk size).
- `new_location.py` sets `t.identity` in `conf.lua` to `rpg-<slug>`, giving each game its own save directory
  (`~/.local/share/love/rpg-<slug>`). The web server reads it from `conf.lua`. Run this generator only in a copy intended for the new town.
- Flow tests must use a temporary `XDG_DATA_HOME` to protect real saves. `make validate` writes reports
  to `maps/source`: a copy that symlinks this directory to the original project is not isolated.
- Flow tests: `SDL_VIDEODRIVER=offscreen love . --test=tests/<x>_flow.lua --mute` (add `--keephome`
  for family tests). Tests under `tests/roda/` apply only to the original Roda map.

## Where things live

| Content | Location |
|---|---|
| Projection (NW origin, reference latitude, 4 m/tile, dimensions) | `data/world.json`, read by `tools/osmlib.py` |
| Downloaded OSM | `cartography/municipio.osm.gz`; municipal boundary: `cartography/limite.osm.gz` |
| Named streets and squares (signs, quests) | `data/streets.json` (`make_streets.py`) |
| Services with NPCs (school, doctor, supermarket…) | `data/services.json` (`make_services.py`, also editable by hand) |
| Shop signs | `data/locals.json` (`make_locals.py`: business directory when available, otherwise OSM) |
| Quests | `data/missions.json` = generated town chapter + chapters from `data/missions.base.json` |
| Map adjustments | `maps/source/map-overrides.json` (bridges, ramps, levels, buildings), `map-edits.json` (editor) |
| Compiled map | `maps/runtime/` (not versioned; generated by `make maps`) |
| In-game place name | `src/place.lua` (`Place.name()`, `Place.of()` → Catalan “de X”/“d'X”) |

## Map details

- **Collision encoding**: bits 0–1 encode the level-0 type; mask 4 marks walkable level 1 (bridge deck),
  8 walkable level -1 (tunnel), 16 a ramp, and 32 a pending-review tile (blocked). An “invisible wall”
  at a bridge usually means a missing ramp or an incorrect OSM `layer`: fix it with `ramps_add` /
  `level_overrides` in `map-overrides.json`, rather than changing `import_osm.py`.
- **An OSM way with `layer=-1` along its entire length** (such as a whole rural path) becomes a tunnel:
  set `level_overrides` to 0 for that `way/<id>`.
- **Overpass**: request only `rel["type"="multipolygon"]`. Including all relations (boundaries, routes)
  previously increased a download from 16 MB to 90 MB.
- `realdata.neutral()` replaces missing orthophotos and elevation data (neither is bundled): flat,
  medium-green terrain. PNOA orthophotos and elevation data (`tools/sat_pipeline.py`, Spain only)
  improve terrain and roof-color accuracy.
- Caves, the tower, the dungeon and the dragon's lair (`decorate_map.py`) look for flat countryside
  away from houses around the starting point. If they do not fit, increase `--size-km` or move them with `landmark_offsets`.
- Hidden objects use unique slug IDs. Avoid duplicate IDs in new generators; the validator rejects them.

## Quests

- Targets: `area:<name>`, `street:<name>`, `service:<id>`, `friend:<id>`, `home`, `nearest:<type>`,
  `spot:<id>`, `door:<id>`, `chest:<id>`. A step can set `family='out'` to move the parents out of the house;
  otherwise they stay home.
- `make_missions.py` replaces Roda locations in base chapters with local ones (`subst`), shopping
  destinations with local supermarkets, and cave doors (`DOORS`). When adding a chapter to
  `missions.base.json`, use targets available everywhere (services, `home`, `nearest:`), or add the required substitutions.
- `make_missions.py` also writes `data/perles.json`: the seven Dragon Pearls in named local squares and parks.
- The web editor (`/editor`, adult hub session) imports and exports campaigns as JSON for an LLM.

## Accessibility for children aged five and up

- Speech: `Tts.say(text, interrupt, voice)`; `Tts.gender(name)` chooses a male or female voice from the
  character's name. On the web, voices are selected by name or pitch adjustment; `tts_word` messages highlight spoken words.
- Uppercase mode (`src/ui/upper.lua`) patches `love.graphics.print/printf` and `Font:getWidth/getWrap`.
- Pronunciation overrides: `data/tts_lexicon.json` (audio only).

## Private data — keep out of the repository

`home.json`, `maps/private/`, `casa_privada*`, `*.local.json` and `~/.local/share/<identity>-sync`
contain family-specific data, including the real home location. Repository-local private files are
covered by `.gitignore`; check `git status` before every commit.

## Known pitfalls

- Piping `make unit` through `grep OK` hid failures: check the exit status (`$?`).
- A mock test map without `in_bounds`/`cell` broke driving assistance: guard those accesses.
- `Net.cancel_all` must preserve in-flight requests (profile synchronization), except `/api/npc_chat`.
- Avoid `pkill -f`/`pgrep -f` patterns that match your own shell.
- Use test profiles when testing in a browser; do not open a child's active save.
