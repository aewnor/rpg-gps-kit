# Proves del mapa original (Roda de Berà)

Aquestes proves fan servir coordenades, edificis i personatges concrets del joc de Roda de Berà (el pont de
l'Avinguda de l'Avenc, el port, el Bonpreu, la torre del Cucurull…). Al kit no passen en un lloc nou: serveixen
d'exemple de com escriure proves de flux (`love . --test=tests/roda/<x>.lua --mute`) per al teu mapa.
